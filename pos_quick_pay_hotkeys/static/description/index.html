POS Quick Pay Hotkeys

Press one key to pay the whole order, print the receipt and start the next order.

Odoo 12 · 13 · 14 · 15 · 16 · 17 · 18 · 19 · 20  |  Community & Enterprise  |  Free

F10

Cash payment

Pays the full amount due in cash, validates the order, prints the receipt and opens a new order.

F12

Card payment

Pays the full amount by card (bank / mada / Visa), validates, prints and opens a new order.

Features

  • Works from the Products screen and the Payment screen.
  • Uses Odoo's own validation, so invoicing, customer checks, cash drawer and stock behave exactly as with the Validate button.
  • Prints the receipt automatically for the hotkey orders only. Your normal printing settings stay unchanged.
  • Picks the payment methods automatically: the cash method for F10, and for F12 the card method whose name contains Card, Bank, Visa, mada, شبكة, مدى… (or the first non-cash method).
  • Payment terminals: if the card method is linked to a payment terminal, the order opens on the Payment screen so the cashier sends the request to the terminal.
  • Works with IoT Box / ePos printers and with the browser printing.
  • No configuration and no new fields. Install and use.

Silent printing without the print dialog

With an IoT Box or an Epson ePos printer, the receipt prints directly. With browser printing, start Chrome with the --kiosk-printing option so the receipt goes to the default printer without a dialog: 

"C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing http://your-odoo-server/pos/web

دفع سريع بالكيبورد لنقطة البيع

زر واحد يدفع كامل الفاتورة ويطبع الإيصال مباشرة ويفتح طلباً جديداً.

  • F10: دفع نقدي بكامل المبلغ + طباعة مباشرة + طلب جديد.
  • F12: دفع شبكة (مدى / فيزا) بكامل المبلغ + طباعة مباشرة + طلب جديد.
  • يعمل من شاشة المنتجات ومن شاشة الدفع.
  • يستخدم نفس تحقق أودو الأصلي (الفاتورة، العميل، درج النقود، المخزون).
  • يختار طريقة الدفع تلقائياً. لاختيار طريقة الشبكة سمّها باسم يحتوي على: شبكة أو مدى أو Card أو Bank.
  • لا يحتاج أي إعداد. ثبّت المديول وابدأ.
  • للطباعة بدون نافذة الطباعة: شغّل كروم بخيار --kiosk-printing أو استخدم IoT Box.
